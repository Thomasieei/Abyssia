# Abyssia

Jeu de farm mobile (Godot 4.7, Android) : monstres aux PV croissants, cartes infinies, boss chronométrés, 6 donjons de 5 à 20 salles, Abysse infinie, équipement et forge, familiers, talents, reliques et ascension, bestiaire, succès, découvertes secrètes, quêtes du jour, classements et arène PvP en ligne (Supabase, tables `aby_*`).

- `game/` : projet Godot
- `tools/render.gd` : rendu des modèles 3D en planches de sprites
- `tools/sim.gd` : simulation d'équilibrage
- L'APK est construit par GitHub Actions et publié dans la release `apk`.
